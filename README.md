# 📖 图书管理系统

基于 Python + MySQL 开发的控制台图书管理系统，实现了图书管理、借阅管理、管理员权限控制等核心功能，并包含多项进阶特性。

## ✨ 功能特性

### 基础功能
- 👤 管理员登录与身份验证
- 📚 图书增删改查 (CRUD)
- 🔄 图书借阅与归还

### 进阶功能 (加分项)
- 👑 **权限管理**：超级管理员与普通管理员角色区分，支持修改密码、新增/删除管理员
- 🔍 **查询优化**：支持按书名模糊查询、按分类/作者筛选，图书列表分页显示（每页5条）
- 🛡️ **数据校验**：图书编号唯一校验，禁止重复添加；输入非数字错误提示
- 📊 **借阅增强**：
  - 同一读者最多借阅 3 本图书限制
  - 借阅超过 30 天自动逾期提醒
  - 查看当前所有已借出图书及借阅详情
- 📈 **数据统计**：自动统计图书总数、已借出/可借阅数量、热门借阅 Top3
- 📂 **批量操作**：支持从 `.txt` 文件批量导入图书信息（事务处理保证一致性）
- ⚡ **性能优化**：使用数据库连接池 (`DBUtils`) 优化连接效率
- 📝 **日志记录**：系统关键操作自动记录到 `log.txt`
